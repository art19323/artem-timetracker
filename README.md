# Трекер времени и доходности проектов

Одна страница (index.html), открывается по адресу https://art19323.github.io/artem-timetracker/

## Что считает
- Целевая ставка (10 / 15 / 20 USD в час) — цель по доходу за час работы.
- По каждому проекту: стоимость, прямые расходы, доход после расходов, затраченные часы, эффективная ставка (доход / часы), бюджет времени по ставке, остаток или превышение, минимальная цена по уже затраченному времени.
- Календарь недели: сколько часов и на что ушло по дням.
- Распределение времени по задачам внутри проекта — видно, где просадка по времени.
- Таймер: старт/стоп на задаче.

## Как хранятся данные СЕЙЧАС
В браузере (localStorage) — отдельно на каждом устройстве. С телефона не видно того,
что введено на компьютере. Для переноса есть «Экспорт JSON» / «Импорт JSON» и «Экспорт CSV».
