# Трекер времени и доходности проектов

Открывать здесь: https://art19323.github.io/artem-timetracker/

## Что считает
- Целевая ставка (10 / 15 / 20 USD в час).
- По проекту: стоимость, расходы, доход после расходов, часы, эффективная ставка
  (доход / часы), бюджет времени по ставке, остаток или превышение, минимальная цена
  по уже затраченному времени.
- Календарь недели: часы и содержание по дням.
- Распределение времени по задачам — видно, где просадка.
- Таймер старт/стоп на задаче.

## Синхронизация телефона и компьютера

Данные лежат в секретном GitHub-гисте и подтягиваются на каждом устройстве, где
включена синхронизация. Один раз на устройстве:

1. Панель «Синхронизация» → вставить токен GitHub с правом **gist**
   (создать: github.com/settings/tokens ; только scope gist, срок — на свой выбор).
2. Нажать «Подключить / синхронизировать».

- Токен хранится в localStorage браузера и **не** попадает ни в файл страницы,
  ни в экспорт JSON.
- Правки уходят в облако автоматически (через 2.5 с после изменения).
- Раз в минуту страница сама сверяется с облаком.
- Если правки есть и здесь, и в облаке — автоматика останавливается и просит выбрать:
  «Взять из облака» или «Отправить в облако». Молча ничего не перезаписывается.
- Гист с данными: `360bdfe340809d2200971e145674c821`, файл `timetracker-state.json`
  (в браузере ID уже подставлен по умолчанию).

## Резервные копии
«Экспорт JSON» / «Импорт JSON» и «Экспорт CSV» — на всякий случай, независимо от синхронизации.
Данные без синхронизации живут только в браузере конкретного устройства.
